How to attack big coding questions

      

        
1. Find the inputs
Circle what data the program needs from the user.

        
2. Find repetition
Look for words such as each, every, 5 times or all items.

        
3. Find decisions
Look for words such as if, valid, correct, greater than or equal to.

        
4. Find totals
Running totals normally start at 0 and are updated inside a loop.

        
5. Find outputs
Make sure you actually output what the question asks for.

        
6. Check indexes
For a 0-indexed array of 5 items, the indexes are 0 to 4.
